# ChainArb 🛡️

**Smart contract engineering and security auditing** for teams building the next generation of on-chain infrastructure.

We operate at the intersection of two disciplines most agencies treat separately: **protocol development** and **adversarial security review**. Every engineer who ships code here has also broken code professionally — our development process is informed by how contracts actually get exploited, not just how they're supposed to work.

---

### ⚙️ Engineering Standards

* **Test-First, Invariant-Driven:** Every stateful contract ships with a Foundry invariant/fuzz suite covering core solvency and access-control properties.
* **Continuous Security Gate:** Slither and Echidna (or Halmos for symbolic checks) run in CI on every PR. Findings block merges until fully triaged.
* **Gas as a Correctness Metric:** We benchmark gas regressions in CI and document every optimization's assembly-level tradeoff.
* **Zero Single Points of Failure:** Internal code reviews are rigorously peer-reviewed by a second engineer who did not write the code.

### 🔍 Process & Onboarding

* **Fixed-Fee Scoping:** Proposals are explicitly scoped by Lines of Code (LOC), architectural complexity, and attack surface—**never an hourly guess**.
* **Incremental Auditing:** Critical and High findings are delivered to you incrementally as they are uncovered, not withheld until the final report.
* **The Deliverable:** You receive a comprehensive Trail-of-Bits-style severity classification report, or a fully deployed, documented, and tested codebase with an engineer handoff call.
